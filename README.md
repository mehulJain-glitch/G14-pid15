## ✨ Features & Capabilities

- **Rich Text Document Editor**: Built using React with native HTML5 DOM contentEditable commands for headings, fonts, text formatting, colors, highlights, and lists.
- **PC Local Storage & Ctrl+S**: Instant offline persistence to PC browser LocalStorage on `Ctrl+S`, automatic snapshot logging, and visual save confirmation badges.
- **Save to PC & Direct Export**: Export documents to PC disk as `.html` (standalone formatted webpage), `.txt` (plain text), `.md` (Markdown), or `.json` (full backup).
- **Import from PC**: Open and import `.html`, `.txt`, `.md`, or `.json` files directly from your computer into the editor.
- **Multi-Tab Live Sync**: Real-time cross-tab synchronization using browser Storage event listeners and debounced LocalStorage state snapshots.
- **User Roles & Permissions**: Role-based permissions supporting **Editor**, **Commenter**, and **Viewer** access levels.
- **Enhanced Motion & Animations**: Spring animations, floating save banners, 3D tilt perspective cards, and glowing paper focus effects.
- **Version History**: Save revision snapshots, preview older document versions, and restore instantly.

## 🛠️ Tech Stack

- **Frontend Core**: React 19, JavaScript (ES6+)
- **State Management**: Zustand
- **Routing**: React Router v7
- **Styling**: Vanilla CSS3 (Design Tokens & 3D Glassmorphism)
- **Build Tooling**: Vite 8
