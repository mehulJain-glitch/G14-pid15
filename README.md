## ✨ Features & Capabilities

- **Rich Text Document Editor**: Built using React with native HTML5 DOM contentEditable commands for headings, fonts, text formatting, colors, highlights, and lists.
- **Multi-Tab Live Sync**: Real-time cross-tab synchronization using browser Storage event listeners and debounced LocalStorage state snapshots.
- **Users Login & Access Control**: Role-based permissions supporting **Editor**, **Commenter**, and **Viewer** access levels with user profile management.
- **Version History**: Save revision snapshots automatically or manually via `Ctrl+S`, preview older document versions, and restore instantly.
- **3D Perspective & Motion UX**: Interactive 3D tilt perspective cards, scroll-triggered entrance animations, and multi-stop liquid metallic shine text headers.
- **Custom Cyber Teal & Sage Theme**: Custom 4-tone palette system (`#0B232A`, `#165355`, `#2D8B6F`, `#8CBF9F`).

---

## 🛠️ Tech Stack

- **Frontend Core**: React 19, JavaScript (ES6+)
- **State Management**: Zustand
- **Routing**: React Router v7
- **Styling**: Vanilla CSS3 (Custom Design System tokens & 3D Glassmorphism)
- **Build Tooling**: Vite 8
